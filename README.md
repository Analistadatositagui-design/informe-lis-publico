# Informe de resultados — Plataformas LIS

Informe directivo de Logística Inteligente Solution. **El contenido está cifrado**:
se necesita la clave de acceso para verlo.

👉 **Ábrelo aquí:** https://analistadatositagui-design.github.io/informe-lis-publico/

Funciona en celular, tablet y computador. No requiere cuenta, instalación ni conexión
más allá de cargar la página.

## Cómo está protegido

| | |
|---|---|
| Cifrado | AES-256-GCM |
| Derivación de clave | PBKDF2-SHA256, 600.000 iteraciones |
| Sal e IV | aleatorios, únicos de este documento |
| Dónde se descifra | en tu dispositivo — la clave no viaja a ningún servidor |

Este repositorio es público, pero **solo contiene el documento cifrado**. Sin la clave
correcta no hay nada legible: ni abriendo la página, ni leyendo el código fuente, ni
descargando el archivo, ni revisando el historial de commits. El texto plano nunca se
subió aquí.

## La clave

Se entrega **por un canal distinto** al del enlace. Si recibiste el enlace por correo,
la clave llega por otra vía; nunca las dos juntas en el mismo mensaje.

## Qué contiene

Resultados de las seis plataformas de LIS, con corte de datos al **13 de agosto de 2026,
14:00 hora Colombia**: métricas de impacto, alcance por centro de distribución, adherencia
como cobertura del universo operativo, calidad del dato y avance de la capa de inteligencia
artificial.

Cada fila con cifras se despliega para ver su respaldo: desglose, advertencias y la
consulta que la produjo.
